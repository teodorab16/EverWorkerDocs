# Overview

Convert CSV data to JSON format for easier processing by other nodes.

# When to Use

Use this node when you need to convert CSV files or data into JSON format for processing by AI nodes or API calls.

# Parameters

* csvData (required) - CSV data to convert
  * Example: `{{input_node.csvFile}}`
